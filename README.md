# CampusFlow

Стартовый Vite-проект по этапам 1–4 практической работы №1.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Маршруты

- `#/events` — каталог
- `#/events/:id` — мероприятие
- `#/events/:id/register` — регистрация

## Что уже реализовано

- каталог мероприятий;
- поиск;
- сортировка;
- фильтры категорий;
- избранное;
- карточка мероприятия;
- вкладки «Описание / Программа / Спикеры»;
- состояния кнопки записи;
- форма регистрации;
- валидация обязательных полей и e-mail;
- loading/success формы;
- empty-состояние каталога;
- базовая адаптивность.

Следующие этапы можно добавлять поверх этой структуры, не переписывая основу.
